# Codebase Doctor evals

Run with `claude plugin eval . --trust-plugin --scaffold --allow-tools Bash Write Edit Agent --no-publish`. Each run starts in an empty workspace, so `fixture.sh` (generated by `scripts/gen-eval-fixture.sh`, run it after changing the fixture) recreates the planted project there; `--scaffold` is required for that.

The eval harness refuses plugin directories whose name contains `( ) [ ] { } * ? ! #` or a backslash. If the checkout lives at such a path, copy it first:

```
rsync -a --exclude .git --exclude node_modules . /tmp/codebase-doctor/ && cd /tmp/codebase-doctor && claude plugin eval . --trust-plugin --allow-tools Bash Write Edit Agent --no-publish
```

`analyze-planted` runs `/codebase-doctor analyze .` in the scaffolded workspace and checks that a health score was reported, the SQL injection was found, and the admin-auth decoy was not reported. The no-plugin baseline arm runs automatically and shows what the plugin adds.

For precision and recall against the full answer key, use `scripts/score-eval.js`:

```
node scripts/score-eval.js cli-standalone/test/fixtures/planted-project/.optimization/report.json cli-standalone/test/fixtures/planted-project.key.json
```
